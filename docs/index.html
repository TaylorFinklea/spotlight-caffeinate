Spotlight Caffeinate

Keep your Mac awake without opening Terminal.

Spotlight Caffeinate is a focused macOS menu bar utility for quick keep-awake sessions, pinned presets, recent-session restart, and optional automations.

Support Privacy Policy GitHub

What It Does

  • Start keep-awake sessions from the menu bar or Spotlight.
  • Save and pin presets for common durations.
  • Extend, stop, or restart your most recent session quickly.
  • Choose display, system, or full keep-awake modes.
  • Optionally enable notifications, launch at login, and automations.

Install

Three supported installation paths. Pick the one that fits your setup.

Menu bar app (Homebrew cask)

The menu bar app with Spotlight actions, presets, and automations:

brew install --cask TaylorFinklea/tap/spotlight-caffeinate

If Gatekeeper blocks first launch, run xattr -dr com.apple.quarantine "/Applications/Spotlight Caffeinate.app" and try again.

CLI only (Homebrew formula)

Terminal-only install for machines that do not need the app bundle:

brew install TaylorFinklea/tap/spotlight-caffeinate-cli

CLI only (binary tarball)

No Homebrew, no xcodebuild, just the prebuilt binary:

curl -fsSL https://github.com/TaylorFinklea/spotlight-caffeinate/releases/latest/download/spotlight-caffeinate-cli.tar.gz \
  | tar -xz -C "$HOME/.local/bin"
ln -sf "$HOME/.local/bin/spotlight-caffeinate-cli" "$HOME/.local/bin/caf"

Already installed the app?

The signed app ships a bundled CLI that shares state with the menu bar app:

/Applications/Spotlight\ Caffeinate.app/Contents/Resources/cli/install-cli.sh
