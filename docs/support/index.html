Spotlight Caffeinate Support

If you need help with Spotlight Caffeinate, have a bug report, or want to request an improvement, use one of the support options below.

Contact

Email support at support@finklea.dev.

Bug Reports And Feature Requests

For bugs, regressions, and feature requests, use GitHub Issues:

github.com/TaylorFinklea/spotlight-caffeinate/issues

What To Include

  • Your macOS version.
  • The Spotlight Caffeinate version you are using.
  • What you expected to happen.
  • What actually happened.
  • Any steps that reliably reproduce the issue.

Spotlight Caffeinate is a menu bar utility for keeping your Mac awake with minimal friction. Support requests are handled by email and GitHub Issues.
