# M2 — 1.0 Release Across All Three Channels

## Goal

A coordinated 1.0 launch where App Store, Homebrew (cask + formula), and signed direct-download are all live and healthy on the same day. This is the milestone the user signed off on when they said "all three channels at 1.0."

## Dependencies

- M1 must be complete. Do not start M2 release-execution work until M1 exit criteria are met.

## Scope

**In**

- App Store Connect execution:
  - Capture the recommended screenshot set (main menu active, main menu idle, presets window, automations window, settings window). Current `docs/screenshots/` set is sufficient as a starting baseline.
  - Set pricing.
  - Submit App Privacy answers ("No data collected"). Draft already exists in `docs/app-store-metadata.md`.
  - Submit App Review notes (menu-bar-only `LSUIElement` launch explained). Draft exists in `docs/app-store-metadata.md`.
- Full signed `/Applications` release checklist pass before submission: menu bar, notifications, launch-at-login, bundled CLI sync, Spotlight actions, every automation trigger type.
- Build and upload the App Store archive via `scripts/package_app_store_release.sh` and Xcode Organizer or Transporter.
- Configure `HOMEBREW_TAP_PAT` repo secret so `.github/workflows/update-homebrew-tap.yml` can push tap updates on release publish.
- Establish `CHANGELOG.md` with a 1.0 entry.
- Bump `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` in `project.yml`, regenerate project, verify `Info.plist` version strings.
- Cut `v1.0.0` on GitHub with both `SpotlightCaffeinate.zip` and `spotlight-caffeinate-cli.tar.gz` assets.
- Verify cask and formula installs both work against the published release.
- Refresh GitHub Pages site (`docs/index.html`, `docs/site.css`) with 1.0 install instructions and current screenshots.

**Out**

- Any new feature work. 1.0 is a release milestone only.
- Refactors that are not required for release.
- Direct-download landing pages beyond GitHub Pages.

## Exit criteria

Matches the M2 exit criteria in `.docs/ai/roadmap.md`. Before closing the milestone, confirm:

- `brew install --cask TaylorFinklea/tap/spotlight-caffeinate` installs the 1.0 app.
- `brew install TaylorFinklea/tap/spotlight-caffeinate-cli` installs the 1.0 CLI.
- `curl -fsSL .../releases/latest/download/spotlight-caffeinate-cli.tar.gz | tar -xz -C <dir>` works.
- App Store page is live and purchasable/free as configured.

## Owner

User or Codex. Claude can execute build/script automation and docs, but App Store Connect submission, cert/profile management, and release publishing should stay user-gated.

## Open questions

- Does the App Store listing ship with a demo video, or screenshots only? Default: screenshots only for 1.0.
- Does 1.0 introduce a signed direct-download DMG, or stay as zip? Default: stay as zip to avoid rework of notarization scripts.
